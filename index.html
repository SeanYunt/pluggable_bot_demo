BluePipe Plumbing

Demo: toggle between multiple chatbot integrations

About

BluePipe Plumbing provides 24/7 emergency plumbing and repairs. This demo site shows how a single page can host multiple third-party chatbot integrations for appointment booking, lead capture, or conversational support.

Switch between the bots with the selector above or use the URL parameter ?bot=landbot.

Demo area

The chat widget will appear as a floating widget in the lower-right corner when opened.
